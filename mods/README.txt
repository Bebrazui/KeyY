СИСТЕМА МОДОВ
=============

Как использовать:
1. Поместите .mod файлы или папки с модами в эту папку
2. Зайдите в меню "Моды" в игре
3. Включите/выключите нужные моды
4. Моды работают ВЕЗДЕ - в меню, в игре, в настройках!

ВСТРОЕННЫЕ МОДЫ:
================
- autopilot.mod - Автопилот (нажмите ] в игре для включения)
- rainbow_notes.mod - Радужные ноты (пример простого мода)
- speed_mod/ - Ускоритель (пример сложного мода с Python кодом)

ФОРМАТ .MOD ФАЙЛА:
==================
{
  "name": "Название мода",
  "version": "1.0", 
  "description": "Описание",
  "author": "Автор",
  "enabled": true,
  "hooks": {
    "on_game_update": ["команда1", "команда2"],
    "on_key_press": ["команда3"],
    "on_draw_ui": ["команда4"]
  },
  "settings": {
    "параметр1": "значение1",
    "параметр2": "значение2"
  }
}

ФОРМАТ ПАПКИ С МОДОМ:
=====================
папка_мода/
├── mod_info.json (обязательно - информация о моде)
└── main.py (опционально - Python код мода)

ДОСТУПНЫЕ ХУКИ:
===============
- on_game_update(state, dt, now_ms) - вызывается каждый кадр
- on_key_press(event, state, settings) - при нажатии клавиши
- on_draw_ui(screen, font, state) - при отрисовке интерфейса
- on_draw_note(screen, note, position) - при отрисовке ноты

ФУНКЦИИ В main.py:
==================
def on_game_update(state, dt, now_ms):
    # Обновление логики мода каждый кадр
    pass

def on_key_press(event, state, settings):
    # Обработка нажатий клавиш
    if event.key == pygame.K_SPACE:
        print("Пробел нажат!")

def on_draw_ui(screen, font, state):
    # Отрисовка UI мода
    text = font.render("Мой мод активен", True, (255, 255, 255))
    screen.blit(text, (10, 10))

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:
======================

Автопилот:
- Нажмите ] ВЕЗДЕ для включения/выключения
- Автоматически играет с точностью 95%
- Показывает "АВТОПИЛОТ [ВКЛЮЧЕН]" на экране

Читы:
- Нажмите Tab ВЕЗДЕ для открытия меню читов
- Доступны: бессмертие, бесконечное HP, идеальная точность
- Автопопадания, без проигрыша, множитель очков
- Активные читы показываются в левом углу

Ускоритель:
- Нажмите + для ускорения игры
- Нажмите - для замедления игры
- Показывает текущую скорость на экране

СОЗДАНИЕ СВОИХ МОДОВ:
=====================
1. Создайте .mod файл с базовой информацией
2. Для простых модов используйте hooks в JSON
3. Для сложных модов создайте папку с main.py
4. Используйте доступные хуки для интеграции с игрой
5. Тестируйте мод в меню "Моды"
