# Ритм-игра на Python (Pygame) с редактором карт

## Установка (Windows)
1. Установите Python 3.10+ с добавлением в PATH.
2. Откройте PowerShell в папке проекта.
3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск
- Главное меню (рекомендуется):
```bash
python -m game.menu
```
В меню стрелками выбирайте: Easy / Medium / Hard или Editor.

- Запуск конкретного уровня напрямую:
```bash
python -m game.main --level levels/sample_level.json
```
- Редактор карт напрямую:
```bash
python -m game.editor --audio path/to/song.ogg --bpm 120 --title "Название песни" --artist "Автор"
```

Поддерживаются OGG/WAV/MP3 (используем pygame-ce/SDL2). MP3 может иметь задержку старта — для карт лучше OGG/WAV.

## Идея геймплея
Под бит трека в центр экрана с четырёх сторон летят квадраты с буквой клавиши. В момент, когда квадрат достигает центра, нужно нажать соответствующую клавишу.

## Управление в игре
- W / A / S / D: Ноты сверху / слева / снизу / справа
- ESC: Выход
- R: Перезапуск уровня

## Управление в редакторе
- Пробел: Пауза/Плей
- Стрелки Влево/Вправо: Перемотка -/+ 1 секунду
- 1/2/3/4: Выбор стороны (Слева/Сверху/Справа/Снизу)
- Q/W/E/R: Установка клавиши на ноту (отобразится буква)
- Enter: Поставить ноту в текущий момент времени
- Backspace: Удалить ближайшую ноту к курсору времени
- S: Сохранить уровень в `levels/` (JSON)

Подсказки выводятся вверху экрана. Внизу отображается таймлайн. Вы можете выставлять ноты строго по сетке, если зададите `--bpm` — появится сетка делений.

## Формат уровня (JSON)
```json
{
  "title": "Название",
  "artist": "Автор",
  "audio": "assets/song.ogg",
  "approach_ms": 1000,
  "hit_window_ms": 120,
  "notes": [
    { "time_ms": 1500, "side": "left", "key": "A" },
    { "time_ms": 2000, "side": "top", "key": "W" }
  ]
}
```
- **approach_ms**: за сколько миллисекунд нота долетает до центра от края.
- **hit_window_ms**: +- миллисекунд точности нажатия.

## Создание примера уровня
1. Подготовьте `assets/song.ogg` или `assets/song.wav`.
2. Запустите редактор, укажите аудио и BPM.
3. Расставьте ноты и сохраните `levels/my_level.json`.
4. Запустите игру на этом уровне.

## Встроенные уровни
- `levels/easy.json`
- `levels/medium.json`
- `levels/hard.json`

Запускаются из меню.
