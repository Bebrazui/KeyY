# Диалог подтверждения выхода

## Что добавлено

Добавлен диалог подтверждения выхода во все экраны меню игры, чтобы предотвратить случайный выход при нажатии ESC.

## Где работает

Диалог подтверждения появляется в следующих экранах:

1. **Главное меню** - при нажатии ESC или закрытии окна
2. **Настройки** - при нажатии ESC 
3. **Выбор уровней для игры** - при нажатии ESC или закрытии окна
4. **Выбор уровней для редактирования** - при нажатии ESC или закрытии окна
5. **Меню модов** - при нажатии ESC или закрытии окна

## Как работает

При нажатии ESC появляется диалоговое окно с вопросом "Вы уверены что хотите выйти?" и двумя кнопками:

- **"Да (Enter)"** - красная кнопка, выход из текущего экрана
- **"Нет (Esc)"** - зеленая кнопка, остаться в текущем экране

## Управление

- **Enter** - подтвердить выход
- **Esc** - отменить выход и остаться
- **Закрытие окна (крестик)** - также показывает диалог подтверждения

## Преимущества

- ✅ Предотвращает случайный выход при спаме ESC
- ✅ Единообразный интерфейс во всех экранах
- ✅ Интуитивно понятное управление
- ✅ Красивый визуальный дизайн с полупрозрачным фоном

## Технические детали

Функция `show_exit_confirmation()` создает модальный диалог с:
- Полупрозрачным темным фоном
- Центрированным окном диалога
- Цветными кнопками (красная/зеленая)
- Обработкой клавиш Enter/Esc

Функция возвращает `True` если пользователь хочет выйти, `False` если остаться.
